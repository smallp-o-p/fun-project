# Initial enemy turns

BattleRuntime owns an opt-in sequential enemy controller. Call `EnableEnemyTurns()` only after designating a player faction and installing result delivery; duplicate enablement is rejected. It also handles an initially active enemy. A single guarded execution entry submits the initiating action, waits for interrupts and completion observers, then drains fresh enemy decisions. Public callers receive the initiating result; every automated submission raises ordinary start/completion notifications. AI never depends on playback and never submits from events. Disposal, terminal outcomes, and faults stop it. Each faction activation has 64 submissions with its last reserved for EndFactionTurn; a drain has 64 times the faction count captured at enablement, even when hooks introduce more factions.

EnemyPolicy receives detached faction-permitted observations and own-unit snapshots only. Pick the lowest-ID actable actor. Consider eight nearest visible conscious hostiles, ten adjacent cells, one empty-magazine reload, and pass/end. Only observed-clear neighbors and at least one observed-clear diagonal flank are legal. Last-seen contacts retain no live references or unseen updates. Goals prefer nearest visible hostile, latest unresolved contact, then adjacent unexplored frontier. Activation memory prevents revisits and repeated no-progress intents; exploration need not eventually succeed.

`EnemyPolicySettings` accepts aggression/caution/range weights 0..200 (default 100), preferred range 0..100 (default 75). Score points: 60*A*D + 100*A*K - 35*C*E + 20*B*R + 20*P + 8*F + 15*L - 2. Quantize normalized features to hundredths away from zero; use long intermediates. D is hit probability times useful nominal health/stun damage divided by observed remaining health (capped 1); K nominal health kill probability; E geometry from permitted cover/distance; R preferred-range improvement; P goal progress; F frontier gain; L empty reload. Only positive choices; deterministic ties attack/reload/move then target ID/destination XYZ. Default D=.25/E=.10 gives 9.50 points. `LatestEnemyDecisions` retains at most 64 detached traces, with `EnemyTurnFallbackReason` identifying passes, suppression, limits, disposal, or faults. Preview spends no ammo or RNG and runs only for the chosen actor.

Presentation keeps EventPlaybackDirector's immediate span-to-FIFO event copy. Initialize meshes/HUD and delivery before enabling AI. Playback preserves moves before later deaths, and segment duration uses captured consecutive coordinates. Input, HP/menu/outcome/return refresh wait for queue drain; empty results and initial terminal outcomes still refresh. Explicit exit cancels tween and queue, ignores late callbacks, and detaches subscriptions before teardown. Historical visuals must use captured values.

BattleScene enables the demo preset `new EnemyPolicySettings(200, 25, 100, 75)` after initial HUD/mesh setup, allowing useful low-damage pistol attacks. Only `resources/battle_types/bomb_defusal.tres`'s grunt loadout gains the existing service pistol; each deployed grunt receives a separate loaded weapon. Other maps, stats, sight and objectives are unchanged. The controller uses ordinary actions and queries without additional packages or frameworks.
